# Nemukhina Offline

**您的文本。可核查的引用。保留在您的电脑上。**

一个用于学习和处理资料的小型本地工作区。无需 AI 模型也能使用：导入 UTF-8 TXT/Markdown，按原文行搜索，打开原文，复制引用并备份资料库。

## 启动

安装 Python 3.10+，下载并解压仓库，在项目文件夹中运行：

```sh
python3 server.py
```

Windows 使用 `py -3 server.py`。打开 **http://127.0.0.1:8765**，切换至 **中文**，点击 **理解分数**。系统会添加专门编写的教学示例。无需安装 Python 包、构建前端、登录账号或连接云端 API。初次下载软件需要网络；本地界面不加载远程资源。

## 可选的本地模型

```sh
python3 server.py --engine /path/to/llama-completion --model /path/to/model.gguf
```

请提前获取官方 llama.cpp 和具有适用许可证的兼容 GGUF 模型。已测试 llama.cpp build 12110，使用模型内置的对话模板。中小学、大学和日常模式只改变提示词，不保证模型能力。

生成仍属于实验功能。真实的俄英中三语测试在操作系统禁止网络的情况下成功运行，但小型测试模型的三次回答均未提供引用。应用会提示缺失或无效的引用编号，不会自动证明回答正确。[验证记录](VALIDATION.md)。

## 限制

所有查询词必须出现在同一行。这是词汇匹配，不是语义搜索或翻译，最多返回 20 条结果。每个文件最多 1 MiB，资料库最多 200 个文档 / 50 MiB。浏览器每批导入最多 8 MiB JSON；备份最多 320 MiB JSON，恢复时校验哈希并合并，不覆盖已有文本。

资料以明文保存在当前目录下的 `data/library.sqlite3`，可使用 `--db` 指定其他路径。请备份，并避免将资料加入 Git。服务仅监听本机回环地址，只供本地单用户使用，不应通过代理对外开放。目前没有 PDF/OCR、语音、预装百科或签名安装包。
