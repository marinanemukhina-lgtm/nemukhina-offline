# Сравнение и лицензии — 2026-11-10

Изучены README и LICENSE [anonnerdfrenzy/survival-llm](https://github.com/anonnerdfrenzy/survival-llm). Его README описывает настольное приложение с готовой библиотекой, поиском источников, импортом документов, памятью и локальной моделью. Это сведения автора; приложение здесь не запускалось и его заявленные показатели не воспроизводились.

| Возможность | Survival LLM, по README | Nemukhina Offline, эта версия |
|---|---|---|
| Интерфейс | Настольное приложение | Локальный браузерный интерфейс + CLI |
| Источники | Готовая большая библиотека и импорт | Только выбранные TXT/MD и синтетические образцы |
| Генерация | Локальные модели, настройка установки | Адаптер llama-completion; три реальных smoke-примера под запретом сети, не оценка качества |
| Память | Сохраняемые заметки | Нет |
| Обновления | Сетевые проверки обновлений | Автоматических проверок нет |
| Учёба и языки | Здесь не оценивались | RU/EN/ZH, три инструкции для режима обучения/общих задач |

Survival LLM заметно шире по заявленным возможностям. Новый проект пока проще и не претендует на равную готовность. Преимущество этой реализации — небольшой проверяемый поиск без сторонних Python-пакетов; его хватает для точных цитат, но не для смыслового поиска.

[LICENSE Survival LLM](https://github.com/anonnerdfrenzy/survival-llm/blob/main/LICENSE) — MIT, copyright 2026 Ronny Fernandez, только код. Библиотечные материалы лицензируются отдельно; см. его SOURCES.md. Здесь ни код, ни библиотека Survival LLM не распространяются.

[PR #206](https://github.com/marinanemukhina-lgtm/nemukhina-system/pull/206), head `26aa7135d7b203bd34f996c49e99e60c84053053`, — draft интеграции локальной библиотеки Studio. Его описание явно исключает подключённую LLM и полный офлайн-запуск Studio. Корневой LICENSE в nemukhina-system не был доступен по API (404); это не основание считать весь репозиторий открыто лицензированным. Поэтому исходники не переносились.

Новый код и синтетические примеры — MIT. Python, отдельно установленный llama.cpp и выбранные веса имеют собственные лицензии. Для проверки отдельно скачана Qwen2.5-0.5B-Instruct Q4_K_M из официального репозитория Qwen (карточка: Apache-2.0); веса не распространяются. Конкретный выбор модели для пользователей ещё не принят, см. VALIDATION.md. Документация параметров движка: https://github.com/ggml-org/llama.cpp/blob/master/tools/completion/README.md.
