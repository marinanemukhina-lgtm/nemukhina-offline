# Сравнение и лицензии — 2026-11-10

Изучены README и LICENSE [anonnerdfrenzy/survival-llm](https://github.com/anonnerdfrenzy/survival-llm). Его README описывает настольное приложение с готовой библиотекой, поиском источников, импортом документов, памятью и локальной моделью. Это сведения автора; приложение здесь не запускалось и его заявленные показатели не воспроизводились.

| Возможность | Survival LLM, по README | Nemukhina Offline, эта версия |
|---|---|---|
| Интерфейс | Настольное приложение | Локальный браузерный интерфейс + CLI |
| Источники | Готовая большая библиотека и импорт | Только выбранные TXT/MD и синтетические образцы |
| Генерация | Локальные модели, настройка установки | Общий диалог и режим источников через llama-completion; 2 модели × 12 задач под запретом сети ОС |
| Память | Сохраняемые заметки | Сохранённые диалоги и ограниченный контекст последних полных обменов; это не долговременная семантическая память |
| Обновления | Сетевые проверки обновлений | Автоматических проверок нет |
| Учёба и языки | Здесь не оценивались | RU/EN/ZH, общие задачи и учебные примеры; качество зависит от модели |

Survival LLM шире по заявленной готовой библиотеке и установке. Nemukhina Offline — небольшой открытый помощник для общих задач со своей историей и дополнительным точным поиском по текстам. Оболочка не требует сторонних Python-пакетов; это не доказательство превосходства по качеству, скорости или готовности. Смыслового поиска и готового установщика здесь пока нет.

[LICENSE Survival LLM](https://github.com/anonnerdfrenzy/survival-llm/blob/main/LICENSE) — MIT, copyright 2026 Ronny Fernandez, только код. Библиотечные материалы лицензируются отдельно; см. его SOURCES.md. Здесь ни код, ни библиотека Survival LLM не распространяются.

[PR #206](https://github.com/marinanemukhina-lgtm/nemukhina-system/pull/206), head `26aa7135d7b203bd34f996c49e99e60c84053053`, — draft интеграции локальной библиотеки Studio. Его описание явно исключает подключённую LLM и полный офлайн-запуск Studio.
