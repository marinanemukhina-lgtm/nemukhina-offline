Настройки


Локальная модель
Один раз подготовьте llama.cpp и модель GGUF. После этого можно работать без интернета. Качество и скорость ответов зависят от модели и компьютера.


Где взять движок и модель
Скачайте официальный выпуск llama.cpp для своей системы и распакуйте архив. Выберите совместимую инструктивную модель GGUF, проверьте её лицензию и требования к памяти. Укажите полные пути к файлам ниже. При первой загрузке модели нужен интернет; приложение ничего не скачивает автоматически.
llama.cpp · GGUF / Hugging Face


Можно положить распакованный движок в папку runtime, а модель — в models рядом с server.py. Поиск проверяет только эти папки.




Ответ модели
Вопрос: 2 + 2. Ожидаемый ответ: 4. Это проверка запуска, а не оценка качества всех ответов. В историю диалогов она не добавляется.
Ваши данные
Резервная копия включает диалоги и материалы. Восстановление добавляет отсутствующие записи, сохраняя текущие. Храните копию в безопасном месте.
Данные хранятся без шифрования. Нет аккаунта и телеметрии. Приложение не выполняет код и действия из ответов модели.
